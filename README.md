# CodeRipple: Wavelet-Based Detection of LLM-Generated Code

Official repository for:

**"CodeRipple: Wavelet-Based Detection of LLM-Generated Code"**

## Overview

Detecting code generated by Large Language Models (LLMs) is essential for ensuring software provenance, security, reliability, and licensing compliance.

Existing training-free code detectors mainly adapt text-based detection methods and rely on global statistics of the Token Perplexity Sequence (TPS), which often fail to capture the subtle differences between human-written and LLM-generated code.

In this work, we introduce **CodeRipple**, a training-free framework that detects LLM-generated code by revealing and exploiting fundamental differences in **local TPS dynamics** through **multiscale wavelet analysis**.

Our key observation is that:

- **LLM-generated code** tends to exhibit narrow and transient perplexity spikes.
- **Human-written code** shows broader and more sustained TPS fluctuations.

To capture these differences, CodeRipple jointly leverages:

- **Stationary Wavelet Transform (SWT)** to characterize TPS fluctuation morphology across scales.
- **Discrete Wavelet Transform (DWT)** to quantify cross-scale energy distribution patterns.
